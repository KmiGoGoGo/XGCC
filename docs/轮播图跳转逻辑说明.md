# 轮播图跳转逻辑说明

## 📋 概述

本文档详细说明轮播图点击跳转的业务逻辑规则。

---

## 🎯 关键字段说明

### 1. connectionType（连接类型）
轮播图的跳转类型标识

| 值 | 说明 | 备注 |
|---|------|------|
| 1 | 外链跳转 | 跳转到外部网页 |
| 2 | 详情页 | 跳转到广告详情页 |
| 4 | 营销活动 | 跳转到营销活动页面 |
| 5 | 小程序路径 | 跳转到指定小程序页面 |

### 2. advertisingLink（广告链接）
轮播图的目标链接地址

- 可以是完整的 URL（如：`https://www.example.com`）
- 可以是内部路由路径（如：`/pages/activity/index`）
- 可以是特殊值 `1`（表示无有效链接）
- 可以为 `null` 或空

### 3. activityType（活动类型）
营销活动的类型标识

| 值 | 说明 |
|---|------|
| 1 | 充值奖励活动 |
| 2 | 累计消费活动 |
| 3 | 单笔折扣活动 |
| 4 | 站点优惠活动 |
| 5 | 邀请奖励 |
| 6 | 新客有礼 |
| 7 | 多人拼团 |
| 8 | 付费会员 |
| 9 | 推广员 |
| null | 无活动类型 |

### 4. marketingId（营销活动ID）
营销活动的唯一标识符

---

## 🔀 跳转逻辑规则

### ⭐ 优先级规则（按顺序判断）

```
规则1（最高优先级）
  ↓ 不满足
规则2
  ↓ 不满足
规则3
  ↓ 不满足
按 connectionType 处理
```

---

## 📝 详细规则说明

### 规则 1：优先使用 advertisingLink（最高优先级）

**条件：**
```javascript
advertisingLink 存在 && advertisingLink !== '1' && advertisingLink !== 1
```

**行为：**
- 判断 `advertisingLink` 是否为外部链接（以 `http://` 或 `https://` 开头）
  - **是外部链接** → 根据平台跳转：
    - APP: 使用 `plus.runtime.openURL()`
    - H5: 使用 `window.open()`
    - 小程序: 使用 webView 组件
  - **是内部路由** → 使用 `uni.navigateTo()` 跳转

**示例：**
```javascript
// 外部链接
advertisingLink = "https://www.example.com"
→ 打开外部网页

// 内部路由
advertisingLink = "/pages/activity/detail?id=123"
→ 跳转到活动详情页
```

---

### 规则 2：特殊情况不执行任何操作

**条件：**
```javascript
advertisingLink === '1' 或 === 1
&& activityType === null
&& connectionType === 1
```

**行为：**
不执行任何操作（直接 return）

**说明：**
这是一个特殊的配置状态，表示该轮播图暂时不需要跳转功能。

**示例：**
```javascript
{
  advertisingLink: '1',
  activityType: null,
  connectionType: 1
}
→ 点击无反应
```

---

### 规则 3：默认跳转到详情页

**条件：**
```javascript
activityType === null
&& (advertisingLink === null || advertisingLink === '1' || advertisingLink === 1)
&& connectionType === 2
```

**行为：**
跳转到广告详情页 `advertisDetail.vue`

**传递参数：**
- id - 广告ID
- title - 标题
- time - 发布时间
- status - 状态
- details - 详情内容（富文本）
- image - 图片
- link - 链接

**示例：**
```javascript
{
  advertisingLink: null,  // 或 '1' 或 1
  activityType: null,
  connectionType: 2,
  title: "新春活动",
  details: "<p>活动详情...</p>"
}
→ 跳转到 /pages/advertisDetail/advertisDetail
```

---

### 其他情况：按 connectionType 处理

如果以上三个规则都不满足，则按照 `connectionType` 的值进行标准处理：

#### connectionType = 1（外链跳转）

```javascript
if (advertisingLink) {
  // APP: plus.runtime.openURL()
  // H5: window.open()
  // 小程序: webView 组件
}
```

#### connectionType = 2（详情页）

```javascript
uni.navigateTo({
  url: `/pages/advertisDetail/advertisDetail?参数`
});
```

#### connectionType = 4（营销活动）

```javascript
if (activityType && marketingId) {
  disposeMarketingActivity(activityType, marketingId);
}
```

#### connectionType = 5（小程序路径）

```javascript
if (path) {
  uni.navigateTo({
    url: path
  });
}
```

## 🌊 完整流程图

```
开始
  ↓
点击轮播图
  ↓
获取参数：connectionType, advertisingLink, activityType, marketingId
  ↓
┌─────────────────────────────────────────┐
│ 规则1: advertisingLink 不为 1？         │
│ ├─ 是 → 判断链接类型                    │
│ │       ├─ 外部链接 → 打开外部网页      │
│ │       └─ 内部路由 → uni.navigateTo   │
│ └─ 否 → 继续下一个规则                  │
└─────────────────────────────────────────┘
  ↓
┌─────────────────────────────────────────┐
│ 规则2: advertisingLink=1                │
│       && activityType=null              │
│       && connectionType=1？              │
│ ├─ 是 → 不执行任何操作 (return)         │
│ └─ 否 → 继续下一个规则                  │
└─────────────────────────────────────────┘
  ↓
┌─────────────────────────────────────────┐
│ 规则3: activityType=null                │
│       && (advertisingLink=null/1)       │
│       && connectionType=2？              │
│ ├─ 是 → 跳转到 advertisDetail.vue       │
│ └─ 否 → 按 connectionType 标准处理      │
└─────────────────────────────────────────┘
  ↓
按 connectionType 处理
  ├─ 1 → 外链跳转
  ├─ 2 → 详情页
  ├─ 4 → 营销活动
  └─ 5 → 小程序路径
  ↓
结束
```

## 📊 常见场景示例

### 场景 1：普通活动详情

```javascript
{
  id: '123',
  title: '双十一活动',
  connectionType: 2,
  advertisingLink: null,
  activityType: null,
  details: '<p>活动详情...</p>',
  image: 'https://example.com/image.jpg'
}
```

**执行逻辑：**
1. 规则1：advertisingLink 为 null，不满足
2. 规则2：advertisingLink 不为 1，不满足
3. 规则3：✅ 满足条件
4. **结果：跳转到详情页**

---

### 场景 2：外部链接推广

```javascript
{
  id: '456',
  title: '合作伙伴',
  connectionType: 1,
  advertisingLink: 'https://partner.example.com',
  activityType: null
}
```

**执行逻辑：**
1. 规则1：✅ advertisingLink 不为 1 且是外部链接
2. **结果：打开外部网页**

---

### 场景 3：内部活动页面

```javascript
{
  id: '789',
  title: '会员专享',
  connectionType: 5,
  advertisingLink: '/pages/member/vip?id=100',
  activityType: null,
  mobilePath: '/pages/member/vip?id=100'
}
```

**执行逻辑：**
1. 规则1：✅ advertisingLink 不为 1 且是内部路由
2. **结果：跳转到 /pages/member/vip?id=100**

---

### 场景 4：营销活动

```javascript
{
  id: '101',
  title: '充值有礼',
  connectionType: 4,
  advertisingLink: '1',
  activityType: 1,
  marketingId: '88888'
}
```

**执行逻辑：**
1. 规则1：advertisingLink 为 1，不满足
2. 规则2：activityType 不为 null，不满足
3. 规则3：activityType 不为 null，不满足
4. 按 connectionType 处理：connectionType = 4
5. **结果：调用营销活动处理，跳转到充值奖励页面**

---

### 场景 5：占位轮播图（不可点击）

```javascript
{
  id: '202',
  title: '即将上线',
  connectionType: 1,
  advertisingLink: '1',
  activityType: null
}
```

**执行逻辑：**
1. 规则1：advertisingLink 为 1，不满足
2. 规则2：✅ 全部满足
3. **结果：不执行任何操作**

## 🔍 调试技巧

### 查看日志

点击轮播图后，控制台会输出详细日志：

```javascript
轮播图点击事件: {...}
轮播图参数: {
  connectionType: 2,
  advertisingLink: null,
  activityType: null,
  marketingId: undefined,
  itemData: {...}
}
规则3: 跳转到详情页
```

### 常见问题排查

#### 1. 点击无反应

**检查项：**
- 是否满足规则2的条件（advertisingLink=1, activityType=null, connectionType=1）
- connectionType 是否为未知值
- 控制台是否有错误信息

#### 2. 跳转错误页面

**检查项：**
- advertisingLink 的值是否正确
- connectionType 的值是否设置正确
- 路由路径是否存在

#### 3. 营销活动无法跳转

**检查项：**
- activityType 是否有值
- marketingId 是否有值
- activityType 的值是否在 1-9 范围内

---

## ⚠️ 注意事项

1. **优先级很重要**
   - 规则按顺序判断，一旦满足某个规则就会执行并返回
   - 规则1的优先级最高

2. **数据类型比较**
   - advertisingLink 可能是字符串 '1' 或数字 1，需要同时判断

3. **外部链接格式**
   - 外部链接必须以 `http://` 或 `https://` 开头
   - 小程序环境需要配置业务域名

4. **参数编码**
   - 跳转详情页时，title 和 details 等参数需要 URL 编码

5. **营销活动参数**
   - connectionType = 4 时，必须同时提供 activityType 和 marketingId
