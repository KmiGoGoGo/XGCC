# 富文本图片自适应解决方案

## 📋 问题描述

在 `advertisDetail.vue` 页面中使用 `rich-text` 组件显示 HTML 内容时，图片大小比例不平衡，可能出现以下问题：

1. 图片超出屏幕宽度
2. 图片显示过小或过大
3. 图片比例失调

**示例问题 HTML：**
```html
<p><img src="https://example.com/image.png"></p>
```

此 HTML 中的图片没有任何样式限制，会按照原始尺寸显示。

---

## ✅ 解决方案

采用**双重保障**的方式：
1. **JavaScript 处理** - 在接收到 HTML 内容时，给所有图片添加内联样式
2. **CSS 样式** - 使用多种兼容的深度选择器作为兜底方案

---

## 🔧 实现细节

### 1. JavaScript 处理 HTML

**位置：** `pages/advertisDetail/advertisDetail.vue` - `formatRichText` 方法

```javascript
formatRichText(html) {
  if (!html) return '';
  
  // 给 img 标签添加样式，使其自适应屏幕宽度
  let formattedHtml = html.replace(
    /<img([^>]*?)>/gi,
    (match, attrs) => {
      // 检查是否已经有 style 属性
      if (attrs.indexOf('style=') > -1) {
        // 如果已有 style，追加样式
        return match.replace(
          /style=["']([^"']*?)["']/gi,
          'style="$1; max-width: 100% !important; height: auto !important; display: block; margin: 10px 0;"'
        );
      } else {
        // 如果没有 style，添加 style 属性
        return `<img${attrs} style="max-width: 100% !important; width: 100% !important; height: auto !important; display: block; margin: 10px 0;">`;
      }
    }
  );
  
  // 处理 p 标签，确保没有固定宽度
  formattedHtml = formattedHtml.replace(
    /<p([^>]*?)>/gi,
    '<p style="max-width: 100%; word-wrap: break-word;">'
  );
  
  return formattedHtml;
}
```

**处理结果：**
```html
<!-- 原始 HTML -->
<p><img src="https://example.com/image.png"></p>

<!-- 处理后 -->
<p style="max-width: 100%; word-wrap: break-word;">
  <img src="https://example.com/image.png" 
       style="max-width: 100% !important; width: 100% !important; height: auto !important; display: block; margin: 10px 0;">
</p>
```

---

### 2. CSS 样式兜底

**位置：** `pages/advertisDetail/advertisDetail.vue` - `<style>` 部分

使用三种深度选择器语法，确保跨平台兼容：

```less
.detail-content {
  // 方式1: /deep/ (Vue2)
  /deep/ rich-text {
    img {
      max-width: 100% !important;
      width: 100% !important;
      height: auto !important;
      display: block !important;
      margin: 10rpx 0 !important;
    }
  }
  
  // 方式2: ::v-deep (Vue2.x / Vue3)
  ::v-deep rich-text {
    img {
      max-width: 100% !important;
      width: 100% !important;
      height: auto !important;
      display: block !important;
      margin: 10rpx 0 !important;
    }
  }
  
  // 方式3: :deep() (Vue3 推荐)
  :deep(rich-text) {
    img {
      max-width: 100% !important;
      width: 100% !important;
      height: auto !important;
      display: block !important;
      margin: 10rpx 0 !important;
    }
  }
}
```

## 🎯 关键样式说明

### 图片样式

| 属性 | 值 | 说明 |
|------|-----|------|
| `max-width` | 100% | 最大宽度不超过父容器 |
| `width` | 100% | 宽度占满容器 |
| `height` | auto | 高度自动，保持比例 |
| `display` | block | 块级元素，独占一行 |
| `margin` | 10rpx 0 | 上下间距 |

### P 标签样式

| 属性 | 值 | 说明 |
|------|-----|------|
| `max-width` | 100% | 最大宽度不超过父容器 |
| `word-wrap` | break-word | 长单词自动换行 |
| `overflow-wrap` | break-word | 内容溢出换行 |

## ⚠️ 注意事项

### 1. 样式优先级

使用 `!important` 确保样式优先级最高，避免被其他样式覆盖。

### 2. 正则表达式

- 使用 `gi` 标志：全局匹配，忽略大小写
- 处理有无 `style` 属性两种情况

### 3. 兼容性

三种深度选择器语法覆盖：
- **Vue 2**: `/deep/`
- **Vue 2.x / Vue 3**: `::v-deep`
- **Vue 3 推荐**: `:deep()`

### 4. 调试

在 `formatRichText` 方法中添加了日志：
```javascript
console.log('格式化后的 HTML:', formattedHtml);
```

可以在控制台查看处理后的 HTML 内容。

## 🚀 扩展建议

### 1. 支持更多标签

可以扩展 `formatRichText` 方法，处理其他 HTML 标签：

```javascript
// 处理 video 标签
formattedHtml = formattedHtml.replace(
  /<video([^>]*?)>/gi,
  '<video$1 style="max-width: 100%; height: auto;">'
);

// 处理 iframe 标签
formattedHtml = formattedHtml.replace(
  /<iframe([^>]*?)>/gi,
  '<iframe$1 style="max-width: 100%; height: auto;">'
);
```

### 2. 图片懒加载

可以给图片添加懒加载属性：

```javascript
return `<img${attrs} loading="lazy" style="...">`
```

### 3. 图片占位符

在图片加载前显示占位符，提升用户体验。

## 📝 常见问题

### Q1: 图片还是超出屏幕？

**原因：**
- 父容器可能有固定宽度
- CSS 样式未生效

**解决：**
1. 检查控制台日志，确认 HTML 已被处理
2. 检查父容器 `.detail-content` 是否有 `padding`
3. 尝试清除缓存重新加载

### Q2: 图片显示模糊？

**原因：** 原图尺寸较小，被拉伸到 100% 宽度

**解决：** 修改样式，只设置 `max-width`，不设置 `width`

```javascript
style="max-width: 100% !important; height: auto !important; ..."
```

### Q3: 图片之间没有间距？

**原因：** `margin` 样式未生效

**解决：** 检查是否有其他样式覆盖了 `margin`
