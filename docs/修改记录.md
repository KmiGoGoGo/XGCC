## 🎯 功能实现详情

### 轮播图跳转类型

#### 类型 1：外链跳转
- **APP 环境：** 使用 `plus.runtime.openURL()`
- **H5 环境：** 使用 `window.open()`
- **小程序环境：** 使用 webView 组件

#### 类型 2：详情页
跳转到新建的 `advertisDetail` 页面，传递参数：
- id - 广告ID
- title - 标题
- time - 发布时间
- status - 状态
- details - 详情内容
- image - 图片
- link - 外链

#### 类型 4：营销活动
根据 `activityType` 跳转到对应的营销页面

#### 类型 5：小程序路径
直接使用 `uni.navigateTo` 跳转到指定路径

## ⚠️ 重要说明

### 关于 WebView 组件

1. **小程序业务域名配置**
   - 在微信公众平台配置业务域名
   - 下载并放置校验文件
   - 只支持 https:// 协议

2. **URL 编码**
   - 必须使用 `encodeURIComponent()` 编码链接
   - 接收时自动 `decodeURIComponent()` 解码

3. **替代方案**
   如果无法配置业务域名，可以改用复制链接方案：
   ```javascript
   uni.setClipboardData({
     data: link,
     success: () => {
       uni.showToast({
         title: '链接已复制，请到浏览器打开',
         icon: 'none'
       });
     }
   });
   ```
