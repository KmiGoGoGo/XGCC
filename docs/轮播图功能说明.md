### 2. 轮播图点击事件

实现了完整的轮播图点击跳转逻辑，支持多种跳转类型：

#### 跳转类型说明

| 类型 | 值 | 功能 | 说明 |
|------|-----|------|------|
| 外链跳转 | 1 | 跳转到外部链接 | 支持 APP、H5、小程序 |
| 详情页 | 2 | 跳转到广告详情页 | 跳转到新创建的详情页面 |
| 营销活动 | 4 | 跳转到营销活动页 | 支持9种营销活动类型 |
| 小程序路径 | 5 | 跳转到指定小程序路径 | 站内页面跳转 |

#### 营销活动类型

1. **充值奖励活动** - `/marketing_page/pages/pay/payAward/payAward`
2. **累计消费活动** - `/homeSub/pages/discount/cumulativeMoney/cumulativeMoney`
3. **单笔折扣活动** - `/homeSub/pages/discount/singleMoney/singleMoney`
4. **站点优惠活动** - `/homeSub/pages/discount/siteOffers/siteOffers`
5. **邀请奖励** - `/marketing_page/pages/invite/invitation/invitation`
6. **新客有礼** - 跳转首页
7. **多人拼团** - `/marketing_page/pages/group/list/index`
8. **付费会员** - `/marketing_page/pages/member/index/index`
9. **推广员** - `/marketing_page/pages/promotion/index/index`

### 2.1 客服类 banner（点击进微信客服，不进富文本详情页）

后端轮播图只有 1/2/4/5 四种连接类型，**没有"客服"类型**。若某张 banner 的诉求是"让用户找客服"
（例如《关于退款问题》公告，`connectionType: 2` + 纯富文本），在端上按 **banner id** 指定即可：

**文件：** `pages/index/index.vue`

```javascript
// 顶部常量，新增此类 banner 时把 id 加进数组
const CUSTOMER_SERVICE_BANNER_IDS = [12];
```

实现方式（复用 `components/common/CustomerServiceButton.vue`）：

1. 模板中该 banner 的 `swiper-item` 内渲染一个**铺满整张图的透明覆盖层**，
   覆盖层里放 `CustomerServiceButton`（内部是 `open-type="contact"` 的 `button`），
   点击即唤起微信客服会话，视觉上不可见（`opacity: 0`，见 `.customer-service-overlay :deep(...)`）。
2. `advertisingLink` 事件处理函数最前面用 `isCustomerServiceBanner(itemData)` 提前 `return`，
   避免按钮点击事件冒泡到 `swiper-item` 后又打开内部富文本详情页（`pages/advertisDetail`）。

> 注意：`open-type="contact"` 仅微信小程序有效；支付宝端点击不会唤起客服（需另行改造）。

### 3. 创建广告详情页

**新建文件：** `pages/advertisDetail/advertisDetail.vue`

#### 页面特性

✅ **自定义导航栏** - 使用 customNavigationBar 组件
✅ **富文本渲染** - 支持 HTML 内容展示
✅ **图片展示** - 轮播图图片自适应展示
✅ **外链按钮** - 底部悬浮按钮跳转外链
✅ **响应式布局** - 适配不同屏幕尺寸
✅ **美观UI设计** - 圆角卡片、渐变按钮

#### 页面接收参数

```javascript
{
  id: '',              // 广告ID
  title: '',           // 标题
  time: '',            // 发布时间
  status: '',          // 状态：1-发布中 2-已结束
  details: '',         // 富文本详情内容
  content: '',         // 备选内容字段
  image: '',           // 图片地址
  link: '',            // 外链地址
  linkUrl: '',         // 备选链接字段
  type: '',            // 连接类型
  linkType: ''         // 链接类型
}
```

#### 样式特点

- 使用渐变紫色主题色
- 卡片式布局，圆角设计
- 富文本内容自适应
- 图片宽度自适应，高度自动
- 底部固定按钮，带阴影效果

## 🔧 使用示例

### 轮播图数据格式

```javascript
lunbao: [
  {
    id: '1',
    title: '活动标题',
    image: 'https://example.com/image.jpg',
    connectionType: 2,           // 跳转类型
    advertisingLink: 'https://example.com',
    mobilePath: '/pages/xxx/xxx',
    details: '<p>详情内容</p>',
    status: 1,
    timeS: '2024-01-01',
    marketingId: '123'
  }
]
```

### 点击跳转示例

```javascript
// 轮播图模板
<swiper-item 
  v-for="(item, index) in lunbao" 
  :key="index" 
  @tap="advertisingLink"
  :data-title="item.title" 
  :data-type="item.connectionType"
  :data-link="item.advertisingLink"
  :data-id="item.id"
  :data-mid="item.marketingId">
  <image :src="item.image" mode="aspectFill" />
</swiper-item>

// 自动跳转到对应页面
```

## 📝 注意事项

1. **数据格式**：确保后端返回的数据包含 `indexAdvertising` 字段
2. **图片地址**：图片 URL 必须以 `http` 或 `https` 开头
3. **跳转类型**：`connectionType` 必须设置正确的值（1、2、4、5）
4. **营销活动**：类型4需要配合 `marketingId` 使用
5. **富文本安全**：富文本内容需要确保安全，防止 XSS 攻击
6. **WebView 组件**：小程序环境下使用 webView 组件打开外链，需配置业务域名（详见 `webView组件说明.md`）
